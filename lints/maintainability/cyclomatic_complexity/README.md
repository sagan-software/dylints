# cyclomatic_complexity

## What it does

Checks the Cyclomatic Complexity of each function, method, and closure, and
warns when the score is 10 or more.

A callable starts at 1. Each `if`, `while`, `for`, `&&`, `||`, `?`, match
guard, and match arm after the first adds 1. A plain `loop` and `.await` add
nothing. A closure gets its own score and does not add to the enclosing
function. The limit of 9 follows the
[NIST structured testing guide](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nbsspecialpublication500-99.pdf)
and [PMD's Cyclomatic Complexity rule](https://docs.pmd-code.org/latest/pmd_rules_java_design.html#cyclomaticcomplexity).

## Why is this bad?

Each decision adds an independent path that a reviewer must follow and a test
must cover. A function with many paths can reach high line coverage while an
untested path still hides a bug. A change to one branch can also affect paths
that look unrelated in the source.

## Known problems

The score counts decisions without judging them. Ten flat validation checks can
be easier to read than three interleaved state changes, and both can score the
same. Paths that can never run together still count.

Code inside macro invocations is not counted, including expressions written as
macro arguments, such as `assert!(a && b)`. Decisions inside called functions
count only toward those functions. A function generated by a macro is not
checked.

## Example

```rust
fn score(a: bool, b: bool, c: bool, d: bool, e: bool, f: bool) -> usize {
    let mut score = 0;
    if a {
        score += 1;
    }
    if b {
        score += 1;
    }
    if c {
        score += 1;
    }
    if d {
        score += 1;
    }
    if e {
        score += 1;
    }
    if f {
        score += 1;
    }
    if a && b && c && d && e {
        score += 1;
    }
    score
}
```

The seven `if` expressions and four `&&` operators give a score of 12.

## Use instead

Move the independent checks into a separate function or replace them with data.

```rust
fn count_set(flags: [bool; 6]) -> usize {
    flags.into_iter().filter(|&flag| flag).count()
}

fn score(a: bool, b: bool, c: bool, d: bool, e: bool, f: bool) -> usize {
    let mut score = count_set([a, b, c, d, e, f]);
    if a && b && c && d && e {
        score += 1;
    }
    score
}
```
